# Milky

A fully local macOS search and action engine intended to become a better replacement for Spotlight.

It will unify apps, files, document contents, screenshots, system actions, and web intents in one fast ranked interface. Search will combine lexical retrieval, semantic and multimodal models, and personalization learned from local usage.

The UI should keep Spotlight's simplicity while supporting richer Raycast-style actions and previews.

Planned stack:

- Swift / SwiftUI / AppKit
- Rust
- Python for ML experimentation
- local-only models and storage

The project is intentionally long-term. The goal is not just to build a launcher, but to progressively own and understand more of the search, ranking, indexing, ML, and systems stack underneath it.
